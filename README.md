This repository contains the planning and requirements documents for a new, centralized University Human Resource and Staff Management System. It is a student-developed project intended to be demonstrated and defended; requirements are deliberately written so they can be refined before implementation.


## Project direction
- One university and one campus for this project scope.
- One central HR department.
- A shared platform used by HR, university management, faculties, departments, supervisors, employees, recruitment panels, applicants and authorized support staff.
- Role-based access control (RBAC) with granular permissions and scope restrictions is a core requirement.
- Digitize HR workflows and records from the beginning; no existing HR application migration is assumed.
